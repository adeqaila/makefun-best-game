**EMBERKEEP** — an original arena-survival twin-stick game. You are the last Keeper of the Ember. In an indigo night, waves of embers (Cinder, Wisp, Husk) crawl in from the arena's edge toward your lantern. Move with WASD, aim with the mouse, click to shoot; each wave gets denser and faster, every 5th wave brings the boss "Ashen Maw", and between waves you pick 1 of 3 upgrades (spread shot, fire rate, shield, magnet, speed…). Score, combo and best score (localStorage). You lose when your HP runs out or the lantern goes dark.

Built for make.fun's "Make the best game" bounty ($1,000): a complete game — title/start screen, play with full HUD (wave, score, combo, best, HP, lantern), upgrade choices, results screen with restart — in plain static files, zero network requests, synthesized WebAudio SFX, deterministic seeded staging for screenshots.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Play: WASD to move, mouse to aim, click (or hold) to shoot, P to pause, M to mute.
